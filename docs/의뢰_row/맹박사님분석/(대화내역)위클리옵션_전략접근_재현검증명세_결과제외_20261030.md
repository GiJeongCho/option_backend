# 위클리옵션 만기일 매수 전략 연구 명세 및 재현 절차

작성일: 2026-10-30
개정: 외국인 단독 및 외국인·기관 동시 수급 히트맵 설계 반영
문서 성격: 결과를 포함하지 않은 연구 설계서. 수익률, 도달 확률, 표본 집계, 조건 순위와 최적 결론을 수록하지 않는다. 아래 숫자는 전략 정의를 위한 매개변수다.

## 1. 목적과 범위

만기일 옵션의 초기 가격 대비 상승 경로를 관찰하고, 경과시간과 상승배수를 이용한 매수 신호 및 시장 지표 필터를 비교한다. 콜·풋을 분리하는 기초 분석과 콜옵션 중심의 필터 결합 분석을 구분한다.

기존 연구 대상 기간은 2023년 8월부터 2026년 9월까지이며, 전체기간·연도별·2026년 월별을 별도 집계한다. 기간은 연구 범위이지 거래 성과가 아니다. 기간을 확장하면 데이터 버전을 새로 등록한다.

시작 전 프로젝트의 AGENTS.md와 위클리옵션_오류교훈_및_검증규칙.md를 읽는다. 과거 보고서의 수익이나 최적 조건을 검증된 입력으로 사용하지 않는다.

## 2. 필요한 원자료

- 옵션: 종목코드, 콜·풋, 행사가, 실제 만기일, 세션, 1분 OHLC, 거래량, 원본 행 번호.
- 코스피200 선물: 주간장 1분 OHLC 및 일별 종가. 연결선물 구성과 만기 교체 기준을 기록한다.
- 코스피200 변동성지수: 일별 OHLC와 거래일.
- 보조 연구용 코스피200 현물 일봉·분봉, 투자자별 일별 수급.
- 거래소 일정과 실제 거래일에 따른 만기 매핑. 휴장일 이동 및 만기 유형을 확인한다.

각 파일의 경로·크기·SHA-256·입수일·상품명·종목코드·단위·시간대·분봉 라벨 의미를 보존한다. 신규 파일은 기존 자료와 분리하여 검사한 뒤 병합한다. 겹치는 날짜의 값이 충돌하면 임의로 덮어쓰지 않는다. 종목이 확인되지 않은 현물 파일은 기초지수 자료로 사용하지 않는다.

## 3. 초기 가격 P0와 후보 옵션

초기 관측창은 만기일 09:00~09:10이다. 기존 PPT의 상승 연구 가격대는 다음과 같으며 양 끝을 포함한다.

| 가격대 | 하한 | 상한 |
|---|---:|---:|
| A | 0.40 | 0.60 |
| B | 0.70 | 0.90 |
| C | 1.00 | 1.20 |

각 종목·만기에서 초기창 내 가격대에 처음 해당하는 실제 OHLC 관측을 찾는다. 동일 분봉에서는 OPEN → CLOSE → HIGH → LOW 순서로 확인한다. 여러 후보는 실제 관측시각이 이른 것을 우선하고, 동률은 가격대 하한 순서로 고정한다. 선택한 가격과 필드를 P0 및 기준시각 t0로 고정한다. 이후 더 유리한 가격으로 기준을 변경하지 않는다.

HIGH·LOW로 선정된 P0는 초기 가격경로의 관측 기준이며 그 가격에 매수했다는 뜻이 아니다. 해당 분봉 안의 정확한 관측 초는 알 수 없다. 조건에 해당하는 관측이 없는 종목은 미선정 사유를 남긴다.

## 4. 시간·배수 신호와 매수

- 경과시간 T: 5분부터 120분까지 5분 간격.
- 신호배수 M: 1.0배부터 5.0배까지 0.5배 간격.
- 신호: 정확히 t0 + T에 라벨된 옵션 종가 C가 C >= M × P0를 충족.
- 해당 시각의 종가가 없으면 신호 관측 불가다. 이전 종가로 채우거나 이후 처음 충족한 시점으로 변경하지 않는다.
- 매수: 신호 라벨 다음 실제 옵션 분봉의 OPEN을 매수가 B로 사용한다. 다음 관측이 신호 라벨에서 3분 이내에 있을 때만 유효하다.
- 신호 종가 매수와 다음 시가 매수를 혼용하지 않는다. 분봉 라벨의 초단위 의미가 확인되지 않으면 틱 단위 실행 가능성을 주장하지 않는다.

각 시간·배수 칸은 별도 가상 시나리오다. 한 옵션이 여러 칸에 포함되어도 실제 계좌에서 전부 매수한 합산 전략으로 해석하지 않는다. 계약 수·예산·동시 신호 선택 규칙은 별도 포트폴리오 연구에서 정한다.

## 5. 시장 지표 분류 시점

### 5.1 일별 5일 이동평균

변동성지수와 선물지수 각각 만기일보다 앞선 마지막 거래일 d의 확정 종가를 사용한다. MA5(d)는 d를 포함하는 최근 5거래일 종가의 단순평균이다. 달력일 평균이나 지수이동평균이 아니다.

- 위: Close(d) > MA5(d).
- 아래: Close(d) < MA5(d).
- 동일: Close(d) = MA5(d).
- 5개 관측 또는 거래일 정합성이 없으면 분류 불가.

표시용 반올림 평균으로 비교하지 않고 원가격 정밀도의 정수 교차곱 또는 Decimal로 판정한다. 만기일 당일 종가는 장중 진입 필터로 사용하지 않는다. 일별 자료만으로 매수 순간의 지수와 장중 5일선 관계를 알 수 없다.

### 5.2 선물 당일 시가

당일 주간장에서 처음 실제 관측된 선물 분봉 OPEN을 시가 O로 고정한다. 야간장 시작가격 또는 임의의 09:00 재설정 가격과 혼용하지 않는다.

옵션 매수봉 라벨에서 정확히 1분 전 선물 분봉 CLOSE F를 찾아 O와 비교한다. 이 방식은 보수적인 매수 직전 가격 대용 기준이며 정확한 매수 순간 틱 가격이 아니다. 해당 선물 분봉이 없으면 분류 불가이며 더 오래된 가격으로 채우지 않는다.

## 6. 비교할 필터

콜·풋 분리 및 각 지표 단독 위·아래 비교를 먼저 수행한다. 콜 결합 연구에서는 콜옵션을 고정 모집단으로 두고 다음 지표를 정의한다.

- V: 변동성지수 전일 종가가 전일 포함 MA5 위.
- O: 매수 직전 선물 대용가격이 당일 주간장 시가 위.
- F: 선물 전일 종가가 전일 포함 MA5 아래.

| 시나리오 | 포함 조건 |
|---|---|
| 콜 전체 | 지표 필터 없음 |
| 선물 5일선 아래 | F |
| 모든 지표 충족 AND | V AND O AND F |
| 하나 이상 충족 OR | V OR O OR F |

콜옵션이라는 모집단 조건을 OR 항에 넣지 않는다. OR에서 여러 항을 충족해도 동일 관측은 한 번만 센다. 한 항이 확실히 참이면 다른 항이 미확정이어도 OR는 참이다. 참인 항 없이 미확정 항이 남으면 미확정이며 확정 거짓과 별도 기록한다. AND도 거짓·미확정을 구분한다.

## 7. 매수 후 상승과 하락 측정

### 7.1 기존 히트맵의 상승 지표

매수봉을 제외하고 이후 실제 관측부터 15:20까지 HIGH >= K × B를 기록했는지 계산한다. 기본 K는 2이며 확장 연구에서는 3·4·5도 각각 구분한다. 매수 이후 관측이 없으면 계산 불가다.

도달 비율의 분모는 해당 칸의 신호·필터·매수·후속가격 조건이 유효한 매수 사례다. 분자·분모·고유 만기일 수·누락과 제외 사유를 함께 보존한다. 이 지표는 고가 도달 빈도이며 실현 수익률이 아니다.

### 7.2 최초 2배 이전 하락

매수봉 OPEN부터 처음 HIGH >= 2B가 되는 시점까지, LOW <= 0.75B 및 LOW <= 0.50B가 먼저 관측되는지 각각 검사한다. 전자는 -25%, 후자는 -50%다. 두 집합은 중첩되므로 더하지 않는다.

- 목표 도달봉보다 앞선 분봉에서 하락 기준이 관측되면 선행 하락으로 판정한다.
- 같은 분봉에서 목표와 하락 기준을 모두 기록하면 OPEN으로 선후관계를 확정할 수 있는지 확인한다.
- OPEN만으로 확정할 수 없으면 동일봉 순서 불명으로 표시하고 유리한 순서를 가정하지 않는다.
- 매수봉 포함 방식과 기존 상승 히트맵의 매수봉 제외 방식을 구분하여 민감도 분석한다.
- 분봉 결측 구간은 경로를 추정하지 않는다. 미관측을 실제 미발생으로 단정하지 않는다.

100% 칸만 사후 선택한 하락 연구는 조건부 진단이다. 이를 전체 전략의 손절 성공률이나 미래 성과로 일반화하지 않는다.

## 8. 중복과 표본의 단위

1. 칸별 사례: T·M별로 각각 집계한다.
2. 고유 진입: 날짜·종목코드·실제 매수시각이 같으면 한 번만 집계한다. 같은 옵션이라도 다른 매수시각은 별도 진입이다.
3. 고유 만기일: 여러 행사가와 진입이 같은 날짜에 집중될 수 있으므로 별도로 집계한다.

같은 날짜의 옵션은 독립 시장 사례가 아니다. 날짜별 동일 가중 평균과 날짜 단위 재표본화도 보조 분석으로 수행한다. 기존 보고서에서는 유효 30건 미만 또는 10만기일 미만을 작은 표본 표시 기준으로 사용하되, 이 기준 통과가 통계적 유의성이나 실전성을 보장하지 않는다.

## 9. 외국인·기관 수급 연구

### 9.1 시장·단위·출처

수급은 사용자 확인 기준인 코스피 현물 전체 통합(KRX/NXT)의 외국인 및 기관계 일별 최종 순매수 금액이며 단위는 억원이다. 외국인·기관계 각각의 원본 날짜·매도금액·매수금액·순매수금액·시트·행 번호를 보존한다. 원본 자료는 `현선물지수데이터/수급/외국인수급.xlsx` 및 `기관수급.xlsx`다. 표시 금액의 매수−매도와 순매수 차이는 원자료 반올림 허용 범위를 명시하고 대조한다. 현재 연구의 표시값 대조 허용치는 1억원이다. 순매수 공란을 매수−매도로 임의 복원하거나 0으로 바꾸지 않는다.

### 9.2 두 가지 모집단을 구분

| 연구 | 날짜 모집단 | 평가 지표 |
|---|---|---|
| 초기 가격 대비 5배와 수급의 관계 | 가격대·P0 규칙에 따라 당일 이후 5배가 관측된 날짜만 선택 | 콜·풋 발생 방향, 발생 옵션 수, 수급 금액의 관계 |
| 수급별 매수 후 2배 히트맵 | 5배 발생 여부로 선별하지 않은 전체 만기일 | T·M 신호 후 실제 관측 매수가 대비 이후 2배 도달 여부 |

앞 행의 조건부 구성을 전체 만기일의 발생 확률로 사용하지 않는다. 또한 P0 대비 당일 5배와 다음 분봉 매수가 B 대비 2배는 서로 다른 지표다.

5배 연구는 P0 관측봉을 제외한 이후부터 15:20까지 HIGH >= 5×P0인지 확인한다. 같은 날짜의 콜·풋은 각각 발생 여부를 기록하고 콜만·풋만·양쪽을 나눈다. 옵션 수와 날짜 수를 혼용하지 않는다.

### 9.3 수급 부호별 분류

외국인 최종 순매수금액을 X, 기관계 최종 순매수금액을 Y로 정의한다.

| 분류 | 조건 |
|---|---|
| 외국인 순매수 | X > 0 |
| 외국인 순매도 | X < 0 |
| 외국인·기관 동시 순매수 | X > 0 AND Y > 0 |
| 외국인·기관 동시 순매도 | X < 0 AND Y < 0 |
| 외국인 매수·기관 매도 | X > 0 AND Y < 0 |
| 외국인 매도·기관 매수 | X < 0 AND Y > 0 |
| 중립 | 두 값이 모두 존재하고 어느 한쪽이 0 |
| 분류 불가 | 필요한 값 중 하나 이상 결측 |

외국인 단독 분석은 기관 결측 때문에 제외하지 않는다. 동시 수급 분석은 두 값이 모두 필요하다. 동시 순매수·동시 순매도 PDF에서 반대 방향을 빼더라도 원장과 전체 격자에는 별도 집단으로 남긴다. 동시 순매수는 두 주체의 합계가 양수라는 뜻이 아니다.

분류 후 전체기간·연도별·2026년 구간별로 콜과 풋을 각각 집계한다. 히트맵은 외국인 순매수/순매도 또는 동시 순매수/동시 순매도의 각 집단 안에서 유효 매수 사례를 분모로 사용한다. 신호가 없는 경우와 자료가 없어 계산할 수 없는 경우를 구분한다.

### 9.4 사후 정보와 실행 가능한 신호

당일 최종 수급은 오전 매수 시점에 확정되지 않는다. 따라서 수급별 히트맵은 당일 시장 환경과 옵션 경로의 사후 관계이며, 오전에 실행 가능한 필터의 성과가 아니다. 실시간 전략으로 확장하려면 실제 매수 시점에 입수한 수급 스냅샷, 공표·수신 시각, 수정 이력 및 지연을 보존해 다시 계산해야 한다. 전일 최종 수급을 사용하는 설계는 별도 전략으로 등록한다.

### 9.5 상관분석 방법

수급 금액과 옵션 발생 수·방향균형·최고 상승배수의 관계를 날짜 단위로 조사한다. 방향균형은 (콜 발생 수−풋 발생 수)/(콜 발생 수+풋 발생 수)이며 분모가 0이면 계산 불가다. 최고 상승배수가 콜·풋 합산 최대값인지 방향별 값인지 명시한다.

Pearson 상관과 동률 평균순위 기반 Spearman 상관을 구분하고 독립 계산으로 대조한다. 날짜 단위 재표본화, 극단값 제외 민감도, 연도별·연도 내 비교를 보조 분석으로 사용한다. 상관계수는 발생 확률이 아니며 인과효과나 미래 성능을 의미하지 않는다. 날짜의 시간적 의존성과 여러 후보 비교에 따른 선택 편향을 별도로 검토한다.

### 9.6 다른 보조 지표

현물·선물의 5·20·60·120·240 이동평균은 일봉과 1분·5분·30분봉을 구분한다. 봉 완성 전 최종 종가를 참조하지 않으며 세션·분봉 집계 기준을 고정한다. 변동성·수급·이동평균을 동시에 탐색하면 후보 증가에 따른 선택 편향을 고려한다.

## 10. 검증 절차

1. 원파일 목록·해시·실행 코드·설정·패키지 버전을 저장한다.
2. 종목·만기·콜풋 매핑, 실제 거래일·세션·분봉 라벨, 중복 충돌·결측·비정상 OHLC를 검사한다.
3. 신규 자료와 기존 자료의 중첩 OHLC를 대조한다. 공급자 표시 이동평균과 직접 계산값은 표시 반올림 차이를 구분한다.
4. P0·정확한 신호 종가·다음 시가·후속 고점과 저점을 관측 경로에서 독립 재계산한다.
5. 요청 시각과 실제 원자료 시각, 필드, 원본 파일·행 번호, 가격 경과시간을 보존한다. 미래 참조와 무단 이전가격 대체를 검사한다.
6. 비교 가능한 동일 시각 옵션 간 행사가 가격관계와 스프레드 상한을 검사한다. 경고·사후 제외는 보존하며 제외 후 결과를 실행 전략으로 포장하지 않는다.
7. 분리 집단의 건수가 원합산과 일치하는지, OR가 중복 없는 합집합인지, AND가 각 집단의 부분집합인지 확인한다. 날짜 수는 집단 간 중첩될 수 있어 무조건 합산하지 않는다.
8. 계산 불가를 0%로 표시하지 않는다. 원자료 일치·산술·시각·가격 일관성·실행 가능성의 검증 상태를 별도로 보고한다.
9. 동일한 시간·배수 및 공통 모집단에서 필터를 비교한다. 날짜·연도 구성의 차이를 공개한다.
10. 수급 분류 원장의 날짜 유일성, 부호 조건 및 전체 조합의 완전한 분할을 독립 재계산한다. 참고표의 수급 금액은 원본과 대조하되 기존 상관·도달 비율을 새 분석 입력으로 사용하지 않는다.
11. 기간을 나누어 조건의 안정성을 점검한다. 이미 탐색에 사용한 기간을 미사용 검증기간으로 부르지 않는다. 이후 미사용 자료로 조건을 고정하여 재검증한다.

## 11. 실현 수익 전략으로 확장할 때 먼저 고정할 항목

현재 고가 도달 연구와 구분하여, 익절·손절·시간청산, 동일봉 동시 도달 처리, 갭 발생 시 체결가격, 거래량·호가와 슬리피지, 수수료·세금·승수, 자본·계약 수·동시 보유 한도·신호 선택·재진입 규칙을 사전에 명세한다.

익절 전 손절 여부를 시간순으로 재생하고 순손익·최대손실·연속손실·자본 대비 낙폭을 계산한다. 손절 미체결과 데이터 결측을 유리하게 처리하지 않는다. 고점 매도를 가정한 잠재수익과 실제 청산 규칙의 수익을 분리한다.

## 12. 제3자에게 전달할 재현 자료

- 본 명세서와 프로젝트 지침·오류 교훈 문서.
- 원자료 해시 목록과 상품·세션·시각 정의, 접근 가능한 원자료 위치.
- 만기 매핑·일별 지표 원장·옵션 후보 선정 원장.
- 관측별 P0·신호·매수·목표·하락 가격과 실제 시각·필드·출처.
- 전체 시간·배수 격자, 원래 사례 수·유효 수·미확정·제외 사유.
- 실행 스크립트·설정·실행 방법 및 독립 검증 기록.

보고서 형식은 가로축 경과시간, 세로축 신호배수의 히트맵을 기본으로 한다. 상승 도달 비율은 빨강 공통 척도, 제목 검정, 표 머리글 녹색, 계산 불가 회색으로 표시한다. 같은 척도에서 기간·집단을 비교하고 분수와 만기일 수를 함께 제공한다.

본 문서는 연구 절차만 정의한다. 특정 조건의 우위·수익성·최적성을 결론내리지 않는다.
