F1. 전역 메뉴 재구성

상단 GNB를 기업은행·대신증권형 드롭다운(메가메뉴)으로 전환
좌측 사이드바는 선택된 대메뉴의 소메뉴만 노출
홈 화면은 메뉴 외 요소 제거, 진입 경로만 보이도록 단순화

F2. 전략 메뉴 노출

상단 "전략" 카테고리 하위에 등록된 전략 전체를 드롭다운으로 나열
현재 활성 전략이 어떤 것인지 식별 표시

F3. 전략 상세분석 화면 (기존 보강)

전략별 MD 상세 설명 렌더링
수익·손실 지표 패널: 누적수익, MDD, 승률, 평균손익
손실 날짜별 리스트는 이 화면 안으로 편입 (목록 → 해당일 차트 드릴다운)
만기일 1분봉 차트 뷰어, 이평선은 전일 데이터부터 이어서 표시

F4. 전략 비교 화면 (신규)

2개 이상 전략 선택 후 동일 기준 비교
기본 정렬은 최신 전략 역순
정렬 토글: 수익률 / 승률 / 최신순
연도별 수익률 비교 테이블·차트는 이 화면에 배치

F5. 엑셀 다운로드 UI

상세·비교 화면 모두에 다운로드 버튼
기간·전략 선택 후 요청 → 백엔드 생성 파일 수신
