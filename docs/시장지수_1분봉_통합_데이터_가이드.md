# 코스피200 현물·선물 1분봉 통합 데이터 가이드

## 1. 신규 원자료 검증 결과

### 현물

- 원본: `코스피200_현물지수_1분_20230801_20260930.xlsx`
- 기간: 2023-08-01 09:01 ~ 2026-09-30 15:30
- 거래일: 769일
- 분봉: 299,730개
- 중복 시각: 0개

### 선물

- 원본: `코스피200_선물지수_1분_20230801_20260930.xlsx`
- 기간: 2023-08-01 08:46 ~ 2026-09-30 15:45
- 거래일: 769일
- 분봉: 315,382개
- 중복 시각: 0개

기존 CSV와 겹치는 구간을 전수 대조한 결과는 다음과 같다.

- 현물 겹침 190,980개 분봉: OHLC 100% 일치
- 선물 겹침 274,314개 분봉: OHLC 100% 일치
- 겹침 구간 종가 최대 절대오차: 현물·선물 모두 0

따라서 신규 XLSX는 기존 자료와 충돌하는 별도 가격계열이 아니라,
기존 자료의 과거 기간을 확장한 통합 원자료로 사용할 수 있다.

거래량 열은 초기 KRX 구간에는 존재하지만 후반 CYBOS 구간에는
비어 있다. 따라서 전체 기간 공통 전략에서는 OHLC 기반 MA·기울기·
수익률·실현변동성을 사용하고, 거래량은 값이 존재하는 구간만 별도
분석해야 한다.

## 2. 실제 로딩 규칙

`app/index_minute_catalog.py`가 다음 우선순위로 정규화한다.

1. 신규 통합 XLSX를 우선 사용한다.
2. 동일 시각의 기존 CSV는 검증에만 사용하고 중복 저장하지 않는다.
3. XLSX에 없는 기존 CSV 시각만 보충한다.
4. 현재 CSV가 보유한 2026-10-01 이후 자료도 이어 붙인다.
5. 원본 크기 또는 수정시각이 바뀌면 통합 캐시를 자동 재생성한다.

현재 통합 결과:

- 현물: 303,921개, 2023-08-01 09:01 ~ 2026-10-19 13:51
- 선물: 319,771개, 2023-08-01 08:46 ~ 2026-10-19 13:53

생성되는 `.cache/market_index` 파일은 속도용 파생물이다. 원본 XLSX와
CSV가 기준이며 캐시를 연구 원자료로 직접 수정하면 안 된다.

## 3. 연결 범위

- 전략 손실일의 현물·선물·VIX 시장상황 API
- 옵션 차트 아래 현물·선물·Basis 동기화 차트
- S6 지표 연구의 현물·선물 RV·기울기·MA·RSI·basis·상관계수
- 앞으로 신규 전략에서 사용하는 장중 현물·선물 특징

판단시점 이후 분봉은 특징 계산에 포함하지 않는다. VIX도 거래일
당일값이 아니라 직전 확정 관측값까지만 사용한다.

## 4. 향후 2024년 옵션 원자료 추가

옵션 파일은 이름에 거래일 `_YYYYMMDD.csv`가 있고 디렉터리 이름에
`[파생 옵션 코스피200 위클리]일중 매매정보(1분)`이 포함되면 주문번호와
관계없이 자동 발견된다.

- 분석 시작 허용일은 2023-08-01이다.
- S6의 과거 `2024-09-24` 고정 시작일은 제거했다.
- 새로 들어온 2024년 만기 그룹도 프로파일을 갱신하면 자동 포함된다.
- 같은 거래일 파일이 두 디렉터리에 중복되면 임의 선택하지 않고
  오류로 중단한다.

추가 후 전체 결과 갱신:

`python backend/analysis/option_5x/refresh_all_backtests.py`

이 명령은 원자료 프로파일, 완료 만기 그룹, 모든 저장 전략과 감사를
차례로 재생성한다. 새 옵션 파일을 복사만 하고 이 명령을 실행하지
않으면 기존 저장 백테스트 결과는 자동으로 바뀌지 않는다.
