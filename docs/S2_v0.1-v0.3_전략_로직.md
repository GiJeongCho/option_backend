# S2-v0.1~v0.3 전략 로직

> 포함 버전: `S2-v0.1`, `S2-v0.2`, `S2-v0.3`  
> 최종 산출물 기준: 2026-09-28 만기

## 1. 계열 목적

S2 계열은 처음부터 하루 한도 500만원을 모두 투입하지 않는다.
250만원으로 시장을 탐색한 뒤 20분 안에 최초 체결가의 1.5배가
확인될 때만 남은 예산을 추가한다.

- 시작자금: 8,000만원
- 방향: CALL·PUT 옵션 매수
- 하루 신규매수 원금 상한: 500만원
- 하루 최대 캠페인: 1회
- 직전 변동성지수 기준: 30 이상
- 진입 프리미엄: 2.50~5.00

## 2. 공통 최초 신호

완료봉에서 다음 조건을 모두 확인한다.

1. 직전 봉 종가는 직전 MA5 이하이고 현재 종가는 MA5 위다.
2. 현재 MA5가 MA20 위다.
3. 현재 종가가 직전 5개 봉의 고가를 돌파한다.
4. 현재 거래량이 직전 20개 봉 평균보다 많다.
5. 현재 프리미엄이 2.50~5.00이다.
6. 신호 시각이 14:30 이전이다.

같은 분에 여러 계약이 통과하면 최근 거래량이 큰 계약, 종목코드
순으로 하나를 선택한다.

## 3. 공통 탐색 매수와 확인 증액

### 3.1 탐색 매수

- 최초 계획원금: 250만원
- 체결: 신호 뒤 5분 안의 다음 실제 거래봉
- 매수가: 다음 거래봉 시가 + 0.01

### 3.2 확인

최초 체결봉부터 20분 동안 완료봉 종가가 최초 체결가의 1.5배 이상인지
확인한다.

### 3.3 증액

20분 안에 1.5배가 확인되면 하루 신규매수 원금 500만원 한도까지
같은 계약을 추가 매수한다. 확인되지 않으면 추가 원금을 넣지 않는다.

## 4. S2-v0.1

### 4.1 성격

24개 탐색·확인 조합을 비교한 뒤 개발 구간에서 선택한 최초
확인 증액 버전이다.

### 4.2 청산

- 완료봉 종가가 최초 체결가의 2배 이상이면 전량청산
- 목표 미도달 잔량은 15:15 시간청산
- 별도 가격 손절 없음
- 세션 종료까지 미체결된 잔량은 0원 평가

## 5. S2-v0.2

### 5.1 v0.1에서 바뀐 점

최초 신호에 MA20 상승 필터를 추가한다.

- 신호봉 MA20이 5분 전 MA20보다 높아야 한다.
- 탐색 250만원, 20분 내 1.5배 확인, 최대 500만원 증액은 같다.
- 2배 전량청산과 15:15 시간청산도 같다.

진입 필터는 2025-10-01~2026-04-30 개발 구간에서 비교한 후보 중
선택했다. 이후 구간은 선택 점수에 넣지 않았다.

### 5.2 최신 성과

- 전체 만기일: 289일
- 실제 거래일: 47일
- 수익일: 29일
- 승률: `61.70%`
- 누적 순손익: `+39,324,000원`
- 최대 낙폭: `-8,546,000원`
- 최고 수익일 1개 제외: `+34,111,000원`
- 최고 수익일 5개 제외: `+19,896,000원`
- 감사 결과: 통과

## 6. S2-v0.3

### 6.1 v0.2에서 바뀐 점

진입과 확인 증액은 S2-v0.2와 같다. 20분 안에 1.5배 확인에 실패한
탐색 포지션의 청산만 바꾼다.

1. 20분 내 확인된 포지션은 최초 체결가 2배에서 전량청산한다.
2. 20분 내 확인되지 않았더라도 이후 완료봉 종가가 최초 체결가의
   1.5배 이상이면 `LATE_1_5_ALL`로 전량청산한다.
3. 위 신호가 없으면 15:15에 시간청산한다.

### 6.2 최신 성과

- 전체 만기일: 289일
- 실제 거래일: 47일
- 수익일: 33일
- 승률: `70.21%`
- 누적 순손익: `+34,286,000원`
- 최대 낙폭: `-8,566,500원`
- 최고 수익일 1개 제외: `+29,073,000원`
- 최고 수익일 5개 제외: `+16,299,000원`
- 지연 1.5배 청산: 18건
- 2배 목표 청산: 15건
- 감사 결과: 통과

승률은 높아졌지만 총손익은 v0.2보다 `5,038,000원` 낮아 승격하지
않았다.

## 7. 버전 차이 요약

### S2-v0.1

- 기본 회복·돌파·거래량 신호
- 250만원 탐색 후 20분 내 1.5배 확인 시 증액
- 2배 전량 또는 시간청산

### S2-v0.2

- v0.1에 MA20 5분 상승 필터 추가
- 진입 뒤 청산은 v0.1과 동일
- S2 계열 선택 버전

### S2-v0.3

- 진입은 v0.2와 동일
- 20분 미확인 포지션도 이후 1.5배에서 전량청산
- 승률은 상승했지만 총손익 저하로 미채택

## 8. 체결·비용 규칙

- 옵션 승수: 250,000
- 수수료: 계약당 편도 500원
- 매수 슬리피지: +0.01
- 매도 슬리피지: -0.01
- 매수·매도 참여율: 분봉 거래량의 최대 10%
- 진입 대기: 신호 뒤 최대 5분
- 수량: 정수 계약
- 만기까지 미체결된 잔량: 0원 평가

## 9. 미래정보 차단

1. 이동평균, 고점, 거래량은 현재 완료봉과 과거 봉만 사용한다.
2. 신호봉에서 즉시 체결하지 않고 다음 실제 거래봉을 사용한다.
3. 변동성 필터는 옵션 거래일보다 앞선 종가만 사용한다.
4. 1.5배 확인은 최초 매수 뒤에 발생한 완료봉만 인정한다.
5. v0.2 필터 선택은 개발 구간만 사용했지만, 전체 전략 연구가 완전한
   사전등록 실험은 아니다.

## 10. 차트 표시

웹의 전략별 분석에서 각 버전을 따로 선택할 수 있다.

- 실제 탐색 BUY
- 확인 뒤 추가 BUY
- 실제 SELL 또는 EXPIRE
- 체결가·수량·수수료
- `TARGET_2X_INITIAL`, `LATE_1_5_ALL`, `TIME` 등 청산 사유

손실 막대나 최악 손실 날짜를 누르면 해당 날짜의 실제 체결 위치를
분봉 차트에서 확인한다.

## 11. 공통 한계와 판정

1. MA20 필터와 지연 청산은 동일 자료의 개발 구간을 탐색해 고른
   규칙이므로 새 만기일 전진검증이 필요하다.
2. 고정 슬리피지와 거래량 10%는 실제 호가 체결을 보장하지 않는다.
3. 고정 가격 손절이 없어 확인 실패 포지션의 손실이 커질 수 있다.
4. 일부 구간은 소수 최고 수익일을 제외하면 성과가 약해진다.

현재 비교 기준은 `S2-v0.2`이며, `S2-v0.1`은 부모 기준,
`S2-v0.3`은 높은 승률과 낮아진 손익을 함께 보는 비교안으로
보존한다.
