# 프로젝트 파일·폴더 구조 정리

코스피200 위클리옵션 연구/백테스트/웹 프로젝트의 전체 구조 안내서다.
(작성 기준: 2026-11, 수시 갱신)

## 0. 최상위

```
c:\project\option
├─ backend\        # 파이썬 분석·백테스트 + FastAPI 서버
└─ frontend\       # React(Vite) 웹 UI
```

- 서버 기동/배포: `backend/docs/서버_실행_가이드.md`, `backend/docs/옵션_배포_운영_정리.md`,
  `backend/docs/NETBITEX_옵션_외부배포_Cloudflare_Tunnel_가이드.md`
- 백엔드는 사용자가 직접 켜고 끈다(에이전트가 기동/종료하지 않음).

## 1. backend\

```
backend\
├─ analysis\option_5x\   # 모든 집계·연구·백테스트 스크립트와 output\
```

### 1.2 backend\analysis\option_5x\  (연구·백테스트 엔진)

파이프라인 재생성 진입점: **`refresh_all_backtests.py`** (STEPS 순서대로 전체 재생성).

  - `count_opportunities_lowband.py` : 0.4 하한 포함본 → `opportunities_lowband.csv`
  - `verify_opportunities.py` : 독립 재검산

  - `minimal_baseline_backtest.py` : ContractGrid·load_expiry_day·체결 엔진(슬리피지/승수/수수료)
  - `strategy6_v01_vix_rv_put_backtest.py` : Tranche·execute_exits 등 재사용 청산엔진
  - `strategy6_v02_vix_ma5_rising_backtest.py` : VixSnapshot·vix_snapshots·previous_snapshot
- 연구(분석) 스크립트
  - `corr_multiple_drivers.py` : 2배/5배/10배 상관·편상관
  - `analyze_2x_vs_10x.py` : 2배 vs 10배(MID vs TEN) 구분·경로신호 분석
  - `analyze_10x_vs_low.py`, `analyze_premium_ranges.py`, `analyze_breakout_opportunities.py` 등
- 전략 백테스트 : `strategy1_backtest.py` ~ `strategy7_dual_sleeve_backtest.py`

- 산출물 : `output\` (각 전략 `*_daily.csv`·`*_trades.csv`·`*_summary.json`,
  집계 `opportunities*.csv`, 로그 `output\refresh_logs\`)

### 2.1 맹박사님분석\

```
맹박사님분석\
├─ 요구사항2.md                         # 이번 작업 요구사항(1~3) + 보류 항목
├─ (대화내역)...재현검증명세_...20261030.md   # 히트맵 재현 명세(핵심 참조)
├─ 위클리옵션...흰색배경수정본.pptx
└─ 매수분석\
   ├─ 매수후2배 / 매수후3배 / 매수후4배 / 매수후5배   # 상승 히트맵(배수별)
   ├─ 매수후2배_콜풋분리\                              # 콜·풋 분리 히트맵
   ├─ 모든조건AND충족 / 모든조건OR충족                # [보류] 지표 결합 필터
   ├─ 변동성지수5일이평위아래                          # [보류]
   ├─ 선물지수5일이평위아래 / 선물지수시가위아래        # [보류]
   └─ 외국인수급위아래 / 외국인-기관동시순매수매도      # [보류] 수급(일봉 사후정보)
```

- **상승 히트맵 축**: 가로=최초가격 관측 후 경과시간 T(5~120분/5분), 세로=신호배수 M(1.0~5.0/0.5),
  셀=매수 후 K배(2/3/4/5) 도달 비율. 가격대 0.4~0.6/0.7~0.9/1.0~1.2 합산 + 콜·풋 분리.
- 자세한 정의·검증은 `plan.md` 26절과 `(대화내역)...재현검증명세...md` 참조.
