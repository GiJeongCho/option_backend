# S5-v0.5~v0.8 무재진입 전략 로직

> 최종 업데이트: 2026-10-13  
> 이 문서는 S5-v0.5의 원래 정의를 기준으로 보존하면서, 이후
> S5-v0.6~v0.8 비교 버전의 변경 규칙과 백테스트 결과를 함께
> 기록한다.

## 1. 목적

S5-v0.5는 다음 요청만 남긴 단순 비교 전략이다.

1. 09:10에 실제 가격이 0.40~1.20인 옵션을 고른다.
2. 0.1 프리미엄 구간별로 500만원을 나눠 매수한다.
3. 실제 체결 후 09:29 완료봉까지 P0의 1.5배에 도달하지 못한
   잔량은 09:30 시가에 손익과 관계없이 전량청산한다.
4. 1.5배에 도달한 계약은 PPT 성공군의 기대 최고배수
   `3.907583 × P0`에서 전량청산한다.
5. 실패청산 뒤에는 어떤 계약에도 다시 들어가지 않는다.

기존 S5-v0.4의 실패대금 지연 재진입과 STAGED 중간 감축을 모두
제거했다.

## 2. S5-v0.5 버전과 상태

- 전략 버전: `S5-v0.5`
- 자료 기간: 2026-01-05~2026-09-28 만기일 67일
- 방향: CALL·PUT 옵션 매수
- 최초 신규매수 원금 상한: 하루 500만원
- 재진입: 없음
- 상태: 연구용, 성과 기준 기각

## 3. P0 선정

1. 각 만기일·계약의 09:00~09:10 실제 거래봉을 시간순으로 읽는다.
2. OHLC 중 하나 이상이 0.40~1.20인 첫 완료 봉을 선택한다.
3. 해당 봉에서 0.40~1.20 범위 안 OHLC 값 중 최댓값을 P0로
   고정한다.
4. 이후 가격을 보고 P0를 다시 선정하지 않는다.

PPT 1,320/633/37/650건은 현재 명시적 원자료 정의에서 정확히
재현되지 않는다. 따라서 해당 빈도는 PPT 주장값으로만 사용한다.

## 4. 09:10 바스켓 매수

1. 09:10 완료 후 5분 안의 다음 실제 거래봉을 찾는다.
2. 그 봉 시가도 0.40~1.20인 계약만 매수한다.
3. 실제 체결가는 `시가 + 0.01`이다.
4. 실제 시가를 기준으로 0.40~0.49, 0.50~0.59처럼 0.1 구간을
   만든다.
5. 활성 구간 수로 500만원을 균등 배분한다.
6. 각 구간 안에서는 계약별 투입원금이 가능한 한 같아지도록
   정수 계약을 배분한다.
7. 구간별 배분 후 남은 돈은 현재 투입액이 가장 작은 구간부터
   다시 배정한다.
8. 한 계약의 매수 수량은 진입 봉 거래량의 10%를 넘지 않는다.
9. 전체 최초 매수원금은 500만원을 넘지 않는다.

정수 계약과 거래량 한도로 실제 최초 투입원금은 일평균
`4,543,295원`이었다.

## 5. 1.5배 확인

- 기준: `분봉 고가 >= 1.5 × P0`
- 시간: 실제 매수 체결 봉부터 09:29 완료봉까지
- 체결 전에 발생한 1.5배 고가는 성공으로 인정하지 않는다.
- 09:29까지 한 번이라도 확인하면 `EARLY_CONFIRMED`다.
- 끝까지 확인하지 못하면 `EARLY_FAILED`다.

## 6. 미확인 포지션 청산

`EARLY_FAILED` 포지션은 09:30 실제 거래봉 시가에서 남은 수량
전부를 한 번에 매도한다. 정확한 09:30 전량청산 요청을 우선해
이 강제청산에는 분봉 거래량 10% 제한을 적용하지 않는다.

- 09:30 시점의 평가손익이 양수여도 청산한다.
- 평가손익이 음수여도 동일하게 청산한다.
- 0.15/0.20 절반감축을 사용하지 않는다.
- 0.03/0.04 잔량청산을 사용하지 않는다.
- 청산대금을 다른 계약 매수에 사용하지 않는다.
- 같은 계약에도 다시 진입하지 않는다.
- 09:30에 실제 거래가 전혀 없는 계약은 이후 09:31 가격을
  사용하지 않고 09:30에 보수적으로 0원 청산한다.

미확인 362건 중 357건은 09:30 시가에 전량 체결됐고, 5건
7계약은 09:30 실제 거래가 없어 0원 청산했다.

실제 결과에서 미확인 362건 중 70건은 수익청산, 292건은
손실청산이었다. 합산 순손익은 `-69,859,500원`, 투입원금 대비
`-33.19%`였다.

## 7. 확인 포지션 기대값 청산

PPT의 30분 내 1.5배 성공 633건은 장중 최고배수 구간이
153/262/92/126건으로 제시돼 있다. 각 구간 하단
1.5/2/5/10배를 가중한 값은 다음과 같다.

`(153×1.5 + 262×2 + 92×5 + 126×10) ÷ 633
= 3.907583배`

`EARLY_CONFIRMED` 포지션은 다음 규칙으로 청산한다.

- 목표: `3.907583 × P0`
- 목표 고가 확인: 다음 실제 거래봉부터 전량매도
- 15:15까지 목표 미도달: 시간청산
- 최종 거래량 부족 잔량: 만기 0원 평가

이 값은 성공 계약의 사후 장중 최고가 구간을 평균한 값이다.
실시간 매도가 가능한 통계적 적정가격이 아니며, 본 전략에서는
사용자 요청에 따른 낙관적 비교 목표로만 사용한다.

실제 결과에서 확인 132건 중 58건은 수익, 74건은 손실이었다.
합산 순손익은 `+61,788,000원`, 투입원금 대비 `+69.12%`였다.

## 8. 재진입 금지

다음 동작은 모두 금지한다.

- 09:30 미확인 계약의 장중 1.5배 재확인 감시
- 실패청산대금 재사용
- 다른 실패 계약으로 교체 진입
- 동일 계약 재매수
- 추가 원금 투입

일별 결과의 지연 신호일, 지연 재진입일, 지연 매수원금은 모두
0이어야 한다. 독립 감사에서 거래·포지션·현금흐름을 각각
재검산했다.

## 12. 차트

웹의 `#strategy-analysis` 전략별 분석에서 S5의 각 버전을
선택할 수 있다.

- `S5-v0.5`
- `S5-v0.6-10X`
- `S5-v0.7-04BIN-EV`
- `S5-v0.7-04BIN-10X`
- `S5-v0.8-STEP10-10X`

기본 선택은 버전 번호가 가장 높은 전략이 아니라 전체 누적수익률이
가장 높은 저장 전략이다. 현재는 `S5-v0.7-04BIN-10X`가 기본으로
표시되며, S5-v0.8은 선택 목록의 전략 5 그룹에서 고른다.

차트 표시:

- 09:10 실제 옵션 프리미엄 OHLC
- 실제 BUY 시각과 슬리피지 포함 체결가
- 09:10 프리미엄 가격선과 실제 매수가격선
- P0 기준선
- 1.5배 확인선
- 선택 버전에 따른 EV 3.907583배 또는 10배 목표선
- 실제 BUY·SELL 화살표
- P0 관측 시각
- 1.5배 확인 시각 또는 09:30 미확인 상태
- 각 체결 수량·가격·청산 사유

현재 진입 엔진은 09:10까지의 완료 정보를 확인한 뒤 다음 실제
거래봉에 체결한다. 따라서 차트에서 09:10 프리미엄과 실제 BUY
가격을 구분해 표시하며, 두 값을 같은 가격으로 오해하지 않는다.

계좌곡선의 손실 막대나 최악 손실 날짜를 클릭하면 해당 날짜의
가장 큰 손실 캠페인 차트로 이동한다.

## 14. S5-v0.5 판정

요청한 단순 로직은 전체 `-8,071,500원`, 5~9월
`-13,604,500원`으로 손실이다. 최고 5일을 제외하면 손실이
`-56,926,500원`까지 커진다.

따라서 S5-v0.5는 구현·차트 비교용으로 보존하지만 채택하지 않는다.
특히 `3.907583배`를 실현 기대값으로 해석하면 안 된다. 새 만기일
전진검증 전에는 S5-v0.2 또는 다른 고정 전략을 대체하지 않는다.

## 15. 후속 버전 변경 이력

### S5-v0.6-10X

S5-v0.5의 진입·1.5배 확인·09:30 미확인 전량청산·무재진입 규칙을
그대로 두고, 확인 계약의 목표만 `3.907583 × P0`에서
`10 × P0`로 변경했다.

- 시작자금: 8,000만원
- 거래일: 66일
- 수익 15일·손실 51일
- 승률: `22.73%`
- 누적 순손익: `+90,911,500원`
- 종료자산: `170,911,500원`
- MDD: `-39,923,000원`
- 최고 3일 제외 순손익: `-5,508,500원`
- 최고 5일 제외 순손익: `-45,112,500원`

10배 목표 변경으로 명목 수익은 크게 증가했지만, 소수의 큰 수익일을
제외하면 손실로 전환되는 꼬리수익 의존 전략이다.

### S5-v0.7-04BIN-EV

진입 대상을 실제 진입 시가 `0.40~0.49`인 단일 구간으로 제한하고
확인 계약은 `3.907583 × P0`에서 전량청산한다.

- 시작자금: 4,000만원
- 거래일: 56일
- 승률: `21.43%`
- 누적 순손익: `+30,797,000원`
- 종료자산: `70,797,000원`
- MDD: `-9,178,500원`
- 최고 3일 제외 순손익: `-19,359,000원`

### S5-v0.7-04BIN-10X

S5-v0.7의 `0.40~0.49` 단일 구간에 S5-v0.6의 10배 전량보유를
결합했다.

- 시작자금: 4,000만원
- 거래일: 56일
- 수익 12일·손실 44일
- 승률: `21.43%`
- 누적 순손익: `+125,739,500원`
- 종료자산: `165,739,500원`
- MDD: `-7,356,500원`
- 최고 3일 제외 순손익: `-7,391,500원`
- 최고 5일 제외 순손익: `-19,765,000원`

현재 저장 전략 중 누적수익률이 가장 높지만, 확인 포지션 10건 중
일부의 10배 이상 급등이 전체 성과를 결정했다. 최고 3일을 제외하면
손실이므로 안정적인 반복 수익으로 해석하면 안 된다.

### S5-v0.8-STEP10-10X

S5-v0.7의 `0.40~0.49` 범위 진입을 폐기하고, 실제 진입 시가가
정확히 다음 9개 가격 중 하나인 계약만 허용한다.

`0.4, 0.5, 0.6, 0.7, 0.8, 0.9, 1.0, 1.1, 1.2`

요청 문장의 `0.11, 0.12`는 가격 순서상 `1.1, 1.2`로 해석했다.
실제로 `0.11, 0.12`를 뜻한 것이라면 별도 버전으로 다시 계산해야
한다.

## 16. S5-v0.8 상세 로직

### 진입

1. P0 선정은 S5-v0.5와 동일하게 09:00~09:10 완료 정보만 사용한다.
2. 09:10 결정 후 5분 안에 나타난 첫 실제 거래봉의 시가를 확인한다.
3. 원시 시가가 `0.4, 0.5, …, 1.2` 중 하나와 정확히 일치할 때만
   진입한다.
4. `0.41, 0.49, 0.59, 1.19` 등 가까운 가격으로 대체하지 않는다.
5. 활성화된 정확 가격 단계 수로 하루 500만원을 균등 배분한다.
6. 같은 가격 단계 안에 여러 계약이 있으면 거래량 한도 안에서
   정수 계약을 가능한 한 균등하게 배분한다.
7. 매수 체결가는 `원시 시가 + 0.01`이다.
8. 재진입은 없다.

### 확인과 청산

- 확인 기준: 체결 후 09:29 완료봉까지 `고가 >= 1.5 × P0`
- 미확인: 09:30 시가에 손익과 무관하게 전량청산
- 09:30 무거래: 이후 09:31 가격을 사용하지 않고 0원 청산
- 확인: `10 × P0` 신호 후 전량청산
- 10배 미도달: 15:15 시간청산 시도
- 거래량 부족 최종 잔량: 만기 0원
- 당일 추가매수·교체매수·재진입: 금지

## 18. S5-v0.8 시작 시드 검증

현재 저장된 계약 수량·진입·청산을 고정하고 현금이 부족한 날만
신규 진입을 생략하는 방식으로 시작 시드를 다시 계산했다.

- 2,000만원 시작 → 순손익 `+53,711,500원`,
  종료 `73,711,500원`, 현금 부족일 0일
- 4,000만원 시작 → 순손익 `+53,711,500원`,
  종료 `93,711,500원`, 현금 부족일 0일
- 8,000만원 시작 → 순손익 `+53,711,500원`,
  종료 `133,711,500원`, 현금 부족일 0일

세 시드 모두 하루 최대 500만원을 충분히 감당했으므로 순손익은
같다. 종료자산 차이는 시작 시드 차이 그대로이며 호가 공백 때문에
생긴 마진 차이가 아니다.

정확 가격 호가가 없거나 거래량 한도로 계약을 배정하지 못하면 실제
투입액이 500만원보다 작아질 수 있다. 이 현상은 같은 데이터와 같은
체결 규칙이라면 시드가 충분한 2,000만·4,000만·8,000만원에서
동일하게 적용된다.
