# S5-v0.4 전략 로직

## 1. 상태와 목적

- 버전: `S5-v0.4`
- 상태: 연구용, 기존 고정 비교 버전 `S5-v0.2` 미대체
- 자료 기간: 2026-01-05~2026-08-31 만기일 60일
- 방향: CALL·PUT 옵션 매수 전용
- 최초 신규매수 원금 상한: 만기일당 500만원
- 목적:
  - 09:00~09:10에 0.40~1.20이 된 옵션을 09:10 이후 선매수
  - 09:30까지 1.5배 확인 여부에 따라 보유·청산 분기
  - 실패 포지션 청산대금만 사용해 장중 지연 1.5배 재진입
  - PPT의 사후 최고배수 목표와 실행 가능한 점진청산을 비교

## 2. PPT 기대값 해석

PPT의 30분 내 1.5배 성공 633건은 최고배수에 따라 다음과 같이
분류돼 있다.

- 1.5~2배: 153건
- 2~5배: 262건
- 5~10배: 92건
- 10배 이상: 126건

각 구간의 하단을 적용한 성공군 조건부 사후 최고배수 기대값은
다음과 같다.

`(153×1.5 + 262×2 + 92×5 + 126×10) ÷ 633
= 3.907583배`

이 값은 성공한 계약의 장중 최고가를 사후에 사용한 값이다.
실시간에 3.907583배 매도가 보장된다는 뜻이 아니다.

순서불명 37건을 제외한 1,283건을 모두 매수하고 목표 미도달을
0원으로 가정한 단일 목표 회수배수는 다음과 같다.

- 1.5배 전량청산: `0.740062배`
- 2배 전량청산: `0.748246배`
- 5배 전량청산: `0.849571배`
- 10배 전량청산: `0.982073배`

따라서 `3.907583배`는 낙관적인 EV 비교 목표로만 사용한다.

## 3. P0와 후보 계약

1. 각 만기일·계약에서 09:00~09:10의 실제 거래봉을 시간순으로
   확인한다.
2. OHLC 중 하나 이상이 0.40~1.20인 첫 완료 봉을 고른다.
3. 해당 봉에서 0.40~1.20 범위 안에 있는 OHLC 값 중 최댓값을
   `P0`로 고정한다.
4. P0 관측 봉 이후의 값을 바꾸거나 사후 저점으로 다시 잡지 않는다.

위 규칙을 그대로 적용한 **현 코드 집계**는 적격 1,325건,
같은 봉 선제외 99건, 후속 봉 성공 460건, 실패 766건이다. 이는
원자료의 확정 정답이 아니다. PPT는 후속 봉 성공을 먼저 판정한 뒤
남은 사건에서만 같은 봉 순서불명을 분리한다. 동일한 최댓값 P0에
PPT 판정 순서만 적용하면 `1,325/537/23/765`가 된다.

PPT 대표 사례와 맞는 “시가가 범위 안이면 시가, 아니면 종가”
우선순위와 PPT 판정 순서를 적용하면 적격/성공/순서불명/실패는
`1,325/624/27/674`다. 다만 고가·저가만 적격인 봉의 우선순위와
제외된 5건의 규칙이 없어 PPT의 `1,320/633/37/650`은 여전히
정확히 재현할 수 없다. 따라서 어느 집계도 원자료의 확정 정답이나
PPT 독립 검증값으로 간주하지 않는다.

## 4. 09:10 바스켓 진입

1. 09:10 완료 후 5분 안의 다음 실제 거래봉을 찾는다.
2. 해당 봉 시가도 0.40~1.20인 계약만 진입 후보로 유지한다.
3. 실제 매수가는 `시가 + 0.01` 슬리피지다.
4. 실제 시가를 기준으로 0.1 프리미엄 구간을 만든다.
5. 500만원을 현재 활성 구간 수로 균등 배정한다.
6. 각 구간 안에서는 계약별 투입원금이 가능한 한 비슷해지도록
   정수 계약을 한 계약씩 배정한다.
7. 각 계약 수량은 진입 봉 거래량의 10%를 넘지 않는다.
8. 구간별 1차 배정 뒤 남은 돈은 현재 투입액이 가장 작은 구간부터
   다시 배정한다.
9. 총 최초 매수원금은 500만원을 넘지 않는다.

정수 계약과 거래량 한도 때문에 항상 정확히 500만원을 채우지는
못한다. 표본의 실제 최초 투입원금은 일평균 `4,577,881원`이다.

## 5. 09:30 1.5배 확인

- 확인 기준: `고가 >= 1.5 × P0`
- 확인 시간: 실제 매수 체결 봉부터 09:30까지
- 체결 전에 이미 나타난 고가는 성공으로 인정하지 않는다.
- 확인 신호가 발생한 봉에서는 체결하지 않고 다음 실제 거래봉부터
  매도한다.
- 09:30까지 확인하지 못하면 실패 포지션으로 분류한다.

## 6. EV 청산안

전략명은 `S5-v0.4-EV`다.

- 조기 확인 포지션: `3.907583 × P0`에서 전량청산
- 09:30 미확인 포지션: 09:30 다음 실제 거래봉부터 전량청산
- 장 마감까지 목표 미도달 잔량: 15:15 시간청산
- 거래량 부족으로 끝까지 매도하지 못한 잔량: 0원 만기평가

이 청산안은 PPT 사후 기대값을 실제 고정 목표로 바꿨을 때의
비교 기준이다. 권장 청산안이 아니다.

## 7. STAGED 청산안

전략명은 `S5-v0.4-STAGED`다.

### 7.1 1.5배 확인 전 감축

P0가 0.40~0.79이면 다음 절대가격을 쓴다.

- 0.15 저가 확인: 최초 수량의 절반 청산
- 0.03 저가 확인: 남은 수량 전량청산

P0가 0.80~1.20이면 다음 절대가격을 쓴다.

- 0.20 저가 확인: 최초 수량의 절반 청산
- 0.04 저가 확인: 남은 수량 전량청산

같은 1분봉에 손절 저가와 1.5배 확인 고가가 함께 있으면 봉 내부
순서를 알 수 없다. 유리한 순서를 선택하지 않고 손절을 먼저
적용한다.

### 7.2 1.5배 확인 후 점진청산

- 1.5배: 최초 확인 후 남은 수량 기준 누적 10%
- 2배: 누적 30%
- 5배: 누적 60%
- 10배: 100% 전량

한 봉에서 여러 목표를 동시에 넘으면 가장 높은 누적 비중까지만
한 번 요청한다. 모든 매도는 신호 다음 실제 거래봉부터 봉 거래량
10% 한도로 체결한다.

## 8. 실패대금 지연 재진입

1. 09:30 미확인 포지션의 남은 수량에 청산 주문을 낸다.
2. 수량이 완전히 청산된 실패 계약만 재진입 감시 대상이 된다.
3. 해당 계약의 마지막 실패청산 이후부터 14:30까지
   `1.5 × P0`를 처음 재확인한 시각을 찾는다.
4. 여러 계약의 확인 시각이 같으면 확인 봉 거래량이 큰 계약,
   종목코드 순으로 하나를 고른다.
5. 확인 다음 5분 안의 실제 거래봉 시가에 0.01을 더해 매수한다.
6. 재진입 체결 시각보다 먼저 실제로 들어온 실패 포지션의
   순매도대금만 예산으로 인정한다.
7. 아직 체결되지 않은 미래 청산대금은 미리 사용하지 않는다.
8. 조기 확인 포지션의 최초 원금과 재진입 원금의 보수적 합계는
   500만원을 넘지 않는다.

재진입 청산은 기존 S5-v0.2 규칙을 사용한다.

- 2배: 수량 절반
- 5배: 남은 수량 절반, 최초 수량 기준 누적 75%
- 10배: 전량
- 미도달 잔량: 15:15 시간청산
- 최종 미체결 잔량: 0원 만기평가

## 9. 공통 비용·체결 규칙

- 옵션 승수: 기존 백테스트 공통 승수
- 매수 슬리피지: +0.01
- 매도 슬리피지: -0.01, 0원 미만 방지
- 매수 수수료: 계약당 500원
- 매도 수수료: 계약당 500원
- 매수 참여율: 분봉 거래량의 최대 10%
- 매도 참여율: 같은 종목·같은 분봉 전체 주문 합계 최대 10%
- 모든 수량은 정수
- 현금흐름, 수수료, 만기 0원 평가를 일별 계좌에 연속 반영

## 10. 미래정보 차단 규칙

- 09:10 이후 실제 다음 봉에서만 매수한다.
- 실제 체결 전 1.5배 고가는 성공 판정에서 제외한다.
- STAGED 감축은 미래의 최종 성공·실패 여부를 미리 알지 않고
  확인 전 모든 포지션에 동일하게 적용한다.
- 같은 봉 손절·확인은 손절 우선으로 고정한다.
- 재진입은 실패청산 후의 확인 신호만 사용한다.
- 재진입 예산은 체결 전에 입금된 순매도대금만 사용한다.
- 장중 최고가로 정한 3.907583배가 사후 값임을 결과에 표시한다.
- 개발·후반 구간은 전체 PPT 기간을 본 뒤 만든 진단 구간이며
  독립 검증으로 부르지 않는다.

## 11. 차트 표시

전략 손실 분석의 거래 차트에서 `S5-v0.4-EV`와
`S5-v0.4-STAGED`를 선택할 수 있다.

공통 표시:

- 09:10 실제 프리미엄 OHLC와 가격선
- 실제 BUY 시각·슬리피지 포함 체결가와 매수가격선
- 실제 BUY 체결: 아래쪽 청록색 화살표
- 실제 SELL 체결: 위쪽 분홍색 화살표
- P0 기준가
- 1.5배 확인선
- 관측 시각과 실제 확인 시각
- 조기 확인·미확인·지연 재진입 분기

EV 초기 포지션:

- P0
- 1.5배 확인선
- 3.907583배 목표선

STAGED 초기 포지션:

- P0
- 0.15/0.20 절반감축선
- 0.03/0.04 잔량청산선
- 1.5·2·5·10배선

지연 재진입 포지션:

- P0
- 1.5배 재확인선
- 2·5·10배 청산선

현재 가격 범위를 크게 벗어난 상단 목표는 캔들 축을 과도하게
압축하지 않도록 차트 선에서는 숨기고, 차트 아래 목표 칩에는
전체 가격을 표시한다.

## 13. 판정

STAGED의 전체 손익은 양수지만 최고 5일을 제외하면 큰 음수다.
후반 손익도 `+853,500원`에 불과하며 독립 표본이 아니다.
PPT 수치도 현재 원자료 정의로 정확히 재현되지 않는다.

따라서 S5-v0.4는 차트·감사·전진검증을 위한 연구 버전으로
유지하고, 기존 S5-v0.2를 대체하지 않는다.
