# 코스피200 위클리옵션 5배 상승 분석 실행 계획

## 1. 목적과 우선순위

현재 단계의 최우선 목표는 계좌 목표 달성 여부를 판정하는 것이 아니라, **원본 최초일인 2023년 8월 이후 전체 구간에서 위클리옵션이 시간순 저점 대비 5배 이상 상승한 횟수와 비용 차감 후 최적 시작 가격대를 정확히 찾는 것**이다. 2023년은 8월부터 시작하는 부분 연도이며, 1.00~5.00은 최초 비교 범위이지 최종 제약이 아니다.

진행 순서는 다음과 같다.

1. 5배·10배 상승 기회 횟수와 분포 측정
2. 기회가 가장 많은 프리미엄 구간 탐색
3. 사전에 실행 가능한 진입 로직 개발
4. 진입과 독립된 청산 로직 개발
5. 두 로직을 결합한 비용 차감 후 수익 최적화
6. 8,000만원 연속 계좌와 만기일별 고정 500만원 투자한도로 평가

현재 **전략 개발·손실 분석 범위는 2025-10~2026-08 고변동성 구간**으로
고정한다. 2023~2025-09 자료는 장기 기회 분포와 데이터 품질 참고에는
사용하지만 현재 고변동성 전략의 선택 점수에 섞지 않는다.

변동성이 낮아진 뒤 사용할 전략은 현재 전략에 포함하지 않는다. 사용자가
추후 별도로 요청할 때 새로운 국면 정의, 진입·청산과 검증 구간을 다시
정하며, 그전에는 계획만 보존하고 구현·최적화를 시작하지 않는다.

## 2. 현재까지 확인한 범위

### 2.1 원본 접근 제한

- 이번 사전 조사에서는 원본 전체를 집계하지 않았다.
- 옵션 데이터 4개 묶음은 각 묶음의 대표 CSV에서 헤더와 초기 5행만 확인했다.
- 변동성지수 엑셀은 시트명, 헤더와 초기 5행만 확인했다.
- 따라서 현재 시점에는 실제 5배 상승 횟수나 최적 프리미엄 결과가 없다.
- 본 계획에서 집계 기준을 확정한 다음 필요한 기간과 열만 제한적으로 읽는다.

### 2.2 파일 묶음

- `주문번호-4831-1`: CSV 668개
- `주문번호-4437-1`: CSV 18개
- `주문번호-4571-1`: CSV 21개
- `주문번호-4831-2`: CSV 42개
- `코스피200 변동성지수.xlsx`: 일봉 엑셀 1개

옵션 파일은 총 749개다. 파일명으로 관찰된 최신 옵션 날짜는 2026-08-31이며, 변동성지수 head의 최신 날짜는 2026-09-11이다. 정확한 최초일, 파일 간 중복과 누락은 1단계 메타데이터 조사에서 확정한다.

### 2.3 옵션 CSV head에서 확인한 스키마

네 묶음의 대표 파일은 모두 다음 열을 사용한다.

`거래일자, 시장ID, 종목코드, 종목명, 기준시각, 만기월, 콜풋구분, 행사가격, 결제월번호, 시가, 고가, 저가, 종가, 거래량, 거래대금, 누적거래량, 누적거래대금`

확인 사항:

- 콜·풋 구분값은 `CALL` 등의 문자열이다.
- 종목명에는 `2605W1`처럼 주차 정보가 포함된다.
- `기준시각`은 4자리 HHMM 형태로 보이나 `0001`, `1800`, `2312` 등 주간장 외 값도 존재한다.
- 행은 시간순으로 정렬되어 있다고 가정할 수 없다.
- 원본에 명시적인 만기일 열이 없으므로 주차 정보와 거래소 만기 달력을 이용한 만기일 판정이 필요하다.

### 2.4 변동성지수 엑셀 head

- 시트: `코스피200 변동성지수`
- 열: `날짜, 시가, 고가, 저가, 종가`
- 일봉 데이터이며 분봉 데이터가 아니다.
- head에서 확인된 2026-09-07~2026-09-11의 값은 대략 39~51 범위다.

당일 종가는 장 종료 전에는 알 수 없으므로 전략의 국면 판정에는 원칙적으로 **직전 거래일 종가**를 사용한다.

## 3. 최초 5배 상승 집계의 고정 정의

횟수는 임의의 저점·고점 조합을 모두 세지 않고 다음 세 수준으로 보고한다.

### 3.1 대상 범위

- 거래일: 2023-08-01부터 옵션 데이터의 최신 날짜까지
- 상품: 코스피200 위클리 콜·풋옵션
- 거래일 종류: 해당 옵션 시리즈의 실제 만기일
- 세션: 우선 한국 주간 정규장
- 시작 프리미엄: `1.00 <= L <= 5.00`

야간장 또는 주간장 외 자료는 섞지 않는다. 정확한 정규장 종료시각은 상품 명세를 확인하여 설정값으로 고정한다.

### 3.2 시간순 5배 사건

한 `거래일자 + 종목코드` 안에서:

1. 분봉을 시간순으로 정렬한다.
2. 저가 `L`이 1.00~5.00인 분봉을 시작 후보로 저장한다.
3. 반드시 그보다 뒤의 다른 분봉에서 고가 `H >= 5 × L`인지 검사한다.
4. 같은 분봉의 저가와 고가로 5배 상승을 인정하지 않는다.
5. 조건을 만족한 종목·거래일은 기본 횟수에서 한 번만 센다.

10배 사건은 같은 방식으로 `H >= 10 × L`을 적용한다.

### 3.3 보고할 세 가지 횟수

1. **고유 종목·거래일 수**
   - 한 옵션 종목이 하루에 한 번이라도 5배 조건을 만족하면 1건
2. **고유 만기일 수**
   - 그 만기일에 콜 또는 풋 중 한 종목이라도 만족하면 1일
3. **비중복 상승 에피소드 수**
   - 첫 목표 도달 후 프리미엄 구간에 재진입한 경우만 새 사건으로 인정
   - 중복 방지 규칙 검증 후 2차 집계에서 제공

첫 결과의 대표값은 1번과 2번이다.

### 3.4 분모

- 종목 기준 발생률 분모: 해당 만기일에 한 번이라도 저가 1.00~5.00을 기록한 고유 종목·거래일 수
- 만기일 기준 발생률 분모: 분석 가능한 모든 유효 만기일 수
- 데이터 누락으로 분석할 수 없는 날은 임의로 제외하지 않고 별도 목록과 사유를 제공한다.

### 3.5 프리미엄 구간

초기 비교 구간:

- 1.00~1.49
- 1.50~1.99
- 2.00~2.49
- 2.50~2.99
- 3.00~3.49
- 3.50~3.99
- 4.00~4.49
- 4.50~5.00

상위 가격대는 0.10 또는 0.25 간격으로 다시 나눠 주변 구간에서도 결과가 유지되는지 확인한다. 시작 프리미엄은 5배 사건을 만든 기준 저가 `L`로 분류한다.

## 4. 고변동성 국면 정의 계획

5배 횟수는 먼저 전체 기간에 대해 계산한 뒤, 동일 결과를 고변동성 국면으로 분리한다.

비교할 국면 기준:

- 직전 거래일 변동성지수 종가가 30 이상
- 직전 거래일 변동성지수 종가가 40 이상
- 당시까지의 과거 값 기준 75백분위 이상
- 당시까지의 과거 값 기준 90백분위 이상

절대 기준은 해석이 쉽고, 백분위 기준은 시장 수준 변화에 대응하기 위한 것이다. 모든 기준의 결과를 먼저 제시하고, 사후 전체 기간에서 가장 좋아 보이는 기준 하나만 선택하지 않는다.

당일 고가·저가·종가는 사후 분석용으로만 사용할 수 있으며 장 시작 전 국면 분류에는 사용하지 않는다.

## 6. 현재 전략 초안

이 초안은 아직 성과가 검증된 전략이 아니라 5배 기회 분석 이후 비교할 기본 구조다.
