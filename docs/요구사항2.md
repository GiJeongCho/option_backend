B1. 전수 검증 (최우선)

전체 매매 로직 재검토
2026년 이후 수익 발생일 전건을 나열해 정상 수익 여부 판정
7/3 109배 같은 이상치 탐지 룰 추가 (수익배수 임계치 초과 건 자동 플래그)
최근 만기일 60~70일치 차트 데이터 전건 확인
4배·5배 수익 구간도 전략별로 동일하게 검증 가능하도록 일반화

B2. 엑셀 익스포트 API

항목: 만기일, 행사가, 콜/풋, 매수/매도 구분, 진입·청산 시각, 체결가, 수익금, 수익배수
전략별·기간별 생성 지원
맹박사님 GPT 교차검증용이므로 컬럼명·단위를 명시적으로 (가공값 없이 원시 체결 기준 병기)

B3. 갭보정 로직 수정

야간장(야간선물) 데이터는 갭보정 대상에서 제외
갭보정 계산 시 전일 데이터부터 포함
수정 전후 결과 차이 리포트

B4. 이동평균 warm-up

모든 이평선을 당일 시가가 아니라 전일(및 그 이전) 봉부터 계산
120선은 warm-up 구간 120봉 이상 확보 후 산출, 미충족 시 NaN 처리(0 또는 당일값 대체 금지)
현재 산출값에 결손·점프 없는지 점검

B5. 전략 비교용 집계 API

전략 메타(생성일, 카테고리) + 성과 집계(수익률, 승률, 연도별 수익률) 제공
정렬 파라미터: 최신순/수익률/승률

B6. 회귀 비교 체계

로직 수정할 때마다 직전 버전 백테스트 결과를 스냅샷으로 저장
버전 간 수익 개선/악화 자동 비교 리포트 생성 (수정이 실제로 수익을 높였는지 상시 확인)
